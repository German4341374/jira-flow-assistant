# Templates

Bug, Story and Support templates are available in Create. All render as plain text in ADF; markdown-looking headings are not interpreted as HTML. The shared renderer replaces supplied named variables and preserves unknown placeholders. UI supplies date; other variables and seven fully configured template types remain planned. Subtask creation takes an existing PAY parent key. Similarity is transparent word-set Jaccard overlap on loaded titles, without cross-project weights or a duplicate assertion.
