# Issue health

Ten transparent checks: summary, description length, acceptance criteria, assignee, priority, mapped estimate, component, labels, due date and recent update. Completed issues are exempt from staleness. Zero is a valid numeric estimate. Acceptance matching recognizes Acceptance Criteria, AC:, Definition of Done, or Given/When/Then text; it does not prove requirements are adequate.

Global staleDays and theme have UI controls. disabledRules is configurable through validated settings JSON using the IDs in packages/core/features.ts. Per-project/type requirements and custom patterns remain planned.
