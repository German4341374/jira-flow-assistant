# Security

Do not use this preview with confidential Jira data. Report vulnerabilities privately through the repository's GitHub security advisory feature if enabled; otherwise request a private contact channel in an issue without disclosing exploit details or secrets. Do not post tokens, Jira exports or company URLs.

Security-sensitive changes must preserve strict imports, API origin restrictions, bounded responses, explicit mutation confirmation and safe text rendering. Consult docs/security.md and docs/authentication.md. No production security guarantee is made for version 0.1.
