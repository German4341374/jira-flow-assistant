# Repository guidance

Keep source, comments and documentation in English. Use synthetic Jira data only. Do not claim production OAuth, real Jira verification or unimplemented features. Never embed client secrets or ask for Jira passwords. Do not bypass server transitions, render raw Jira HTML, silently retry writes or remove bulk confirmation. Keep all development caches and temporary files on D when working on this Windows machine. Run npm run verify and npm audit before publishing. Prefer small Conventional Commits.
